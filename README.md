# Free Online Tools by Yash Dhanjwal

A fully functional, modern, fast, and responsive online free web tools website.

## 🎯 Purpose
The website provides free, browser-based tools for everyday users with no login required, clean UI, fast processing, and privacy-focused design.

## 🧩 Core Features

### PDF Tools
- **Merge PDF**: Combine multiple PDFs into one.
- **Split PDF**: Separate PDF pages into individual files.
- **Compress PDF**: Reduce PDF file size.
- **Rotate PDF**: Change the orientation of PDF pages.
- **Unlock PDF**: Remove password protection.
- **Watermark PDF**: Add text watermark to PDF.
- **PDF to Word/Excel**: Extract content to editable formats.
- **PDF to JPG/PNG**: Save PDF pages as images.
- **JPG to PDF**: Convert images to PDF.

### Image & File Tools
- **Image Compressor**: Compress JPG/PNG/WebP.
- **Image Resizer**: Resize images to specific dimensions.
- **ZIP / UNZIP**: Compress or extract ZIP files.
- **Text to PDF**: Convert plain text to PDF.

### Utility Tools
- **Word Counter**: Detailed text analysis.
- **JSON Formatter**: Prettify and validate JSON.
- **Base64 Converter**: Encode/Decode Base64.
- **Online Notepad**: Auto-saving notes.

## ⚙️ Technical Stack
- **Frontend**: React, Tailwind CSS, Vite, Lucide React, Framer Motion.
- **Libraries**: pdf-lib, pdfjs-dist, browser-image-compression, jszip.
- **Backend**: Node.js, Express, Multer (for temporary file handling).

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
1. Clone the repository.
2. Install frontend dependencies:
   ```bash
   cd frontend
   npm install
   ```
3. Install backend dependencies:
   ```bash
   cd backend
   npm install
   ```

### Running Locally
1. Start the backend:
   ```bash
   cd backend
   node server.js
   ```
2. Start the frontend:
   ```bash
   cd frontend
   npm run dev
   ```
